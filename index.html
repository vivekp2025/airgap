Offline Python Wheel Hub

Get Flask, scientific libraries, or any PyPI package with resolved dependencies for an air-gapped PC. Builds run in your own GitHub repository; download the final ZIP in your browser.

1 · Target computer and packages

You may use version constraints like Flask==3.1.2 or extras like requests[socks]. Packages must have matching prebuilt wheels; no source compilation is attempted.

2 · Run dependency resolver

  1. Open your repository's Actions tab.
  2. Open Build offline Python wheelhouse and click Run workflow.
  3. Paste package names into packages; select the same Python and platform chosen above; click the green Run workflow button.
  4. Open the successful run. Under Artifacts, download the ZIP. It contains every resolved wheel, a manifest, requirements, and an offline installation BAT file.
Open GitHub Actions


3 · Copy to air-gapped PC
Extract the artifact ZIP (if GitHub adds an outer ZIP, extract that too), move the offline-wheels-cp…zip to your disconnected PC, and extract it. Run INSTALL_OFFLINE.bat, or the pip command below with your actual Python path:
python -m pip install --no-index --find-links=wheelhouse -r requirements.txt
Before downloading, verify the actual interpreter with python -c "import sys,platform;print(sys.version);print(platform.architecture())". The offline PC must already have Python and pip.
No API key or GitHub token is needed on this site. This is a static GitHub Pages interface; GitHub Actions uses pip's dependency solver. The browser does not run package installation.
